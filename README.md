# Azure DevOps Audit Agent API


## 📖 Project Description
**Azure DevOps Audit Agent API** is a solution designed to deliver **auditing, governance, and automation** within the Azure DevOps ecosystem.  
The project exposes a REST API documented with **OpenAPI/Swagger**, making it easy to integrate with intelligent agents (such as Foundry or Copilot) and other applications.

It addresses a common challenge in large organizations: the **lack of visibility and control over users, licenses, and groups** in Azure DevOps.  
With this API, teams can query critical data, automate administrative tasks, and ensure greater security and transparency in access management.

---

## 🎯 Goals
1. **Audit Projects and Users**  
   - Count and list active projects.  
   - Retrieve the number of users and their license types.  

2. **Manage Groups and Permissions**  
   - Add users to specific groups.  
   - Remove users from groups when necessary.  
   - List project administrators and resolve access hierarchies.  

3. **Automation and Integration**  
   - Provide clear, documented REST endpoints.  
   - Enable integration with intelligent agents and CI/CD pipelines.  
   - Support continuous auditing as part of DevOps workflows.  

4. **Security and Governance**  
   - Ensure only authorized users have access to critical functions.  
   - Provide transparency on who has access to what.  
   - Support compliance and internal/external audits.  

---

## 🌍 Impact
- **For DevOps teams**: simplifies user and project administration.  
- **For IT managers**: provides centralized visibility and control.  
- **For organizations**: enhances security, reduces risks of unauthorized access, and strengthens governance.
